# Private reference material

Use this folder for licensed or internal source material that should **not** be web-served for a particular deployment.

Pass 4 intentionally places `Nanda-I 2024-2026.pdf` in `pdfs/` because this package is configured according to the deployer's stated institutional non-profit license and the explicit request to make that PDF publicly available. The `pdfs/` directory is served at `/docs/`.

Do not assume the same deployment decision applies automatically to other copyrighted references. Put additional licensed books/files in this private folder unless the applicable institutional agreement also authorizes their intended public/software use.

Pass 5 used institutionally supplied Spanish NIC 8 and NOC 7 source books during audit. The deployment package records hashes/provenance in `data/nnn_source_manifest.json` but intentionally does not copy those books into this repository/package unless the deployment owner separately requests public/private bundling under the applicable licence.

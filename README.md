## 🇬🇧 English (UK)

A full-stack, bilingual API and web dashboard designed to streamline Nursing Care Systematisation (SAE) and provide rapid access to Brazilian Public Health Policies (SUS). 

This project bridges the gap between technology and humanised clinical care, built to elevate health literacy and support evidence-based practice on the frontlines of nursing.

### ✨ Features
* **Bilingual SAE / NNN Database:** Instantly query NANDA nursing diagnoses, alongside corresponding NIC interventions and NOC expected outcomes in both Portuguese and English.
* **SUS Policy Explorer:** Navigate national public health directives, including PNAISM (Women's Health), PNAISH, PNAISC, and more, complete with official PDF documentation mapping.
* **Modern UI/UX:** A fully responsive, dark-mode dashboard built with Tailwind CSS.
* **Production-Grade Architecture:** Self-hosted on a cloud environment using a robust backend and secure reverse proxy.

## 🇧🇷 Português (BR)

Uma API e dashboard web full-stack e bilíngue, concebido para otimizar a Sistematização da Assistência de Enfermagem (SAE) e fornecer acesso rápido às Políticas Nacionais de Saúde Pública (SUS). 

Este projeto preenche a lacuna entre a tecnologia e o cuidado clínico humanizado, construído para elevar o letramento em saúde e apoiar a prática baseada em evidências na linha de frente da enfermagem.

### ✨ Funcionalidades
* **Base de Dados SAE / NNN Bilíngue:** Consulte instantaneamente os diagnósticos de enfermagem da NANDA, juntamente com as respectivas intervenções (NIC) e resultados esperados (NOC) em português e inglês.
* **Explorador de Políticas do SUS:** Navegue pelas diretrizes nacionais de saúde pública, incluindo PNAISM (Saúde da Mulher), PNAISH, PNAISC, entre outras, com mapeamento completo da documentação oficial em PDF.
* **UI/UX Moderno:** Um dashboard totalmente responsivo em modo escuro, construído com Tailwind CSS.
* **Arquitetura de Nível de Produção:** Hospedado de forma autônoma em ambiente cloud, utilizando um backend robusto e proxy reverso seguro.

---

## 🛠️ Tech Stack / Tecnologias
* **Backend:** Python, FastAPI, SQLAlchemy, Uvicorn
* **Frontend:** HTML5, Tailwind CSS
* **Infrastructure:** Nginx (Reverse Proxy), Systemd (Background Service Manager)
* **Security:** Let's Encrypt / Certbot (SSL/HTTPS)

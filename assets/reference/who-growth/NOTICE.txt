calculate WHO paediatric growth z-scores.

NORMALIZATION

The JSON files in this directory are normalized machine-readable forms
of the corresponding upstream WHO-maintained reference tables. Their
numeric LMS/reference content is not intentionally altered.

The Clinical Reference Hub calculation code is an independent
implementation validated against official WHO Anthro / AnthroPlus
example vectors.

BRAZILIAN INTERPRETATION

BRAZIL_SISVAN.json is a locally authored structured interpretation
layer derived from Brazilian Ministry of Health / SISVAN guidance. It
does not modify the WHO numerical reference values.
